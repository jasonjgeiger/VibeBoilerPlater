# Vibe Code Project Boilerplate

A modern boilerplate for vibe-related projects with built-in documentation and code generation tools.

## Project Structure

```
.
├── .cursor/           # Cursor IDE configuration
│   ├── rules/         # Rules for Cursor should interact with you and code
├── .copilot/          # GitHub Copilot configuration
├── .git/              # Git repository data
├── docs/              # Project documentation
│   ├── changelog/     # Technical changes 
│   ├── journal/       # Chat history with agents and models
│   ├── templates/     # Code generation templates
│   └── prd.md         # Product Requirements Document
├── src/               # Source code directory
├── .gitattributes     # Git line ending configuration
├── .gitignore         # Git ignore rules
├── LICENSE            # MIT License
└── README.md          # Project documentation
```

## Documentation System

The project uses a structured documentation system to maintain consistency and track changes:

- **Changelog**: Technical changes and milestones in `docs/changelog/`
- **Journal**: Development history and decisions in `docs/journal/`
- **Templates**: Code generation templates in `docs/templates/`

## Getting Started

1. Clone the repository
2. Review the documentation in `docs/`
3. Start developing with the provided templates

## Development Guidelines

- Follow the documentation structure
- Use the provided code templates for consistency
- Keep the development journal updated with changes
- Stay scrappy - prefer simple solutions over complex architectures
- Maintain security and privacy standards
